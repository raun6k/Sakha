# Sakha frontend visual system
The user-pinned reference world is extended directly in code. Operate mode prioritizes a usable farm review and decision workflow.

Evergreen #103e31 navigation and #146b4a actions; ivory #f8f7ee canvas; white panels; dark #18382e text and #53675e secondary text; muted gold #a9812c accent. Status uses text with icons alongside color. Lora variable is the serif display voice; Karla variable is body/control voice, self-hosted under OFL (license files in public/assets). Latin supported by current English UI; future scripts require language work.

Desktop: 246px scrollable sidebar, four primary destinations then six secondary links; fluid main with maximum readable content width. Home keeps seven specified sections. Conversation/workspace use a 3:1 main/context layout; below 900px context follows main, and below 700px four-item fixed bottom navigation replaces sidebar. Composer remains in document flow with room above bottom navigation. Panels adapt to near-full-screen mobile and use Radix focus management.

Setup: three steps About you / Land and water / Current farming; optional name/location, area and source, situation and crop. Agent entries open Chat by default; explicit About links preserve informational access. Sidebar Agents expands all nine roles, with an equivalent mobile dialog. Home uses a short time-based greeting within the panorama under a white readability gradient. Categories Climate & resources / Crop decisions / Business & support. Scenario builders save hypothetical records without changing farm facts. Details and consequential confirmations share a dialog; ordinary inline tasks stay inline.

Panels: 14px radius, subtle downward shadow, 24px desktop padding / 18px mobile. Headings have more separation above than below. Focus uses gold and evergreen outlines. Charts are native SVG with null gaps and tables; no chart library selected. Motion is one brief content reveal and button feedback, with visible default content and reduced-motion override.

Decorative farm panorama generated by built-in imagegen. Prompt: photographic rural Indian landscape, lush green fields, low foothills, scattered palms and warm morning light; wide panorama, natural documentary texture, no text/logos/people/UI. The image is decorative and cannot imply farm location or conditions. Production asset is public/assets/farm-panorama.webp, converted from generated image without editing original references.
