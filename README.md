# Sakha

Sakha is a new project. This repository currently holds the starter layout: a short agent guide, environment placeholders, and local docs.

## Layout

- `README.md` — project overview
- `AGENTS.md` — notes for coding agents (kept out of git locally)
- `.env` — local environment variables
- `docs/` — longer notes (kept out of git locally)

## Setup

Copy values into `.env` before running anything that depends on them. Do not commit secrets.
